# 恋爱力实验室 · Love Power Lab

> 依恋理论 × 情绪脑科学背书的恋爱能力自适应测评系统
>
> Adaptive relationship-competence assessment backed by attachment theory & affective neuroscience.

一个**单文件、零依赖、零后端**的 Web 应用：打开 `index.html` 即可运行，可部署到任意静态托管（GitHub Pages / Vercel / Netlify）。

## 这个项目是什么

「恋爱力实验室」是一个用 **vibe coding** 方法从 0 到 1 完成的完整产品闭环实战：不是土味情感测试，而是用心理学量表设计的思路做差异化——**依恋理论 × 情绪脑科学**做科学背书，用自适应测评算法（简化版 CAT）替代固定题库。

## 核心功能

| 功能 | 说明 |
|---|---|
| **6 维度能力模型** | 冲突修复、情绪识别与共情、依恋安全感、边界与自我、沟通表达、承诺与投入 |
| **60 道情景题** | 每维度 10 题，难度 1–5 级，含考察点、解析、常见陷阱标签 |
| **简化版 CAT 自适应出题** | 每维度按当前能力动态调整题目难度：答对升难度、答错降难度，18 题完成测评 |
| **雷达图诊断** | 6 维能力可视化，点击分数可查看计分依据（可解释性） |
| **证据链诊断** | 诊断结论强制引用具体题号 + 你的选择 + 陷阱模式，不搞巴纳姆话术 |
| **复测对比** | 优先抽未做过的新题，双雷达叠加展示成长轨迹 |
| **恋爱风格文字报告** | 基于 top2 维度生成你的恋爱风格类型、核心优势组合、潜在挑战、第一优势深度解读 |
| **规划方向** | 列出恋爱中需要补偿的能力 + 适合找的伴侣类型（匹配度条 + 特质标签） |
| **分阶段行动计划** | 短期（1-3个月）/ 中期（6-12个月）/ 长期 可执行清单 |
| **资源推荐** | 不给链接给关键词（戈特曼、《依恋》《非暴力沟通》），稳定可验证 |
| **分享文案生成** | 一键生成小红书风格分享文案（含风格类型、短板、补偿方向、伴侣画像） |
| **边界兜底** | 断点续答、防重复提交、空状态、跳过机制、localStorage 持久化 |

## 技术要点

- **纯原生**：HTML + CSS + Vanilla JS，单文件 76KB，无任何依赖
- **简化 CAT 算法**：`分数 = 旧分 × 0.7 + 本题贡献 × 0.3`，按维度独立追踪能力估计
- **数据建模**：题目结构化标注（维度/难度/分值/考察点/解析/陷阱标签），等价于一个小型标注数据集
- **可解释性**：每个诊断结论可回溯到具体作答证据
- **已通过功能模拟测试**：CAT 终止条件、计分区间、复测抽题、断点续答均有自动化断言覆盖

## 产品方法论（这个项目怎么做的）

按照完整的 PM 工作流推进，而非直接写代码：

1. **需求分析** — 目标用户、使用场景、用户旅程（落地页 → 测评 → 结果 → 诊断 → 建议 → 复测 → 分享）
2. **竞品差异化** — 相对固定题库的测评站，用 CAT 自适应 + 科学背书做壁垒
3. **数据建模入库** — 6 维度 × 10 题 × 难度梯度，全部人工标注
4. **算法实现** — 简化版计算机化自适应测验（Computerized Adaptive Testing）
5. **功能闭环** — 弱点诊断 → 资源推荐 → 复测对比，形成「测-学-再测」闭环
6. **测试兜底** — 断点续答、防重复提交、空状态、边界值测试
